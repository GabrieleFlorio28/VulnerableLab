Struttura del repository VulnerableLab

- `sql-injection/` : esempio funzionante di applicazione vulnerabile a SQL Injection
- `broken-auth/`, `privilege-escalation/`, `misconfiguration/` : cartelle scaffold per gli altri scenari
- `docker-compose.yml` : orchestrazione dei servizi
- `scripts/` : script di utilità per avviare/fermare/reset

Aggiungi qui le istruzioni dettagliate per ogni scenario durante lo sviluppo e il testing.
